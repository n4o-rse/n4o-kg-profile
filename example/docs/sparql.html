Linked Open Ogham

Linked Open Data representation of Irish Ogham stones, their inscriptions, readings and find spots, linked to Wikidata, OpenStreetMap and Pleiades.

There is no SPARQL endpoint and no server. The graph is fetched as a static file and parsed in your browser with rdflib under Pyodide. That is deliberate: an archived copy of this repository stays queryable without a service having to be kept alive for it.
